## 💡 Common Questions

**Q: Can I upgrade from Free to Premium later?**
A: Yes! Upgrade anytime. All your data is preserved.

**Q: What happens if I don't renew Premium?**
A: Your site continues working with all Free features. Premium data is preserved but premium features become read-only until renewal.

**Q: Can I get a refund if Premium doesn't work for me?**
A: Yes, 30-day money-back guarantee, no questions asked.

**Q: Do I need technical skills?**
A: Free version requires basic WordPress knowledge. Premium includes setup assistance and training.

**Q: Can Premium really replace NationBuilder and NGP VAN?**
A: For most campaigns (local, state, congressional), yes. Presidential campaigns may still need some specialized tools, but will save significantly by using CampaignPress as the foundation.

**Q: Is my data secure?**
A: Yes. Both versions follow WordPress security best practices. Premium includes advanced security features, automatic backups, and SOC 2 compliance planning.

**Q: Can I use this for a PAC or non-profit?**
A: Yes! Works for candidates, PACs, non-profits, advocacy organizations, and political parties.

**Q: What if I need custom features?**
A: Premium includes developer console and full API access. Custom development available at $150/hour for premium users.

## 🚀 Getting Started

### Free Version
1. Download from WordPress.org
2. Install via **Appearance > Themes > Add New**
3. Activate theme
4. Import demo content (optional)
5. Customize via **Appearance > Customize**

### Premium Version
1. Purchase at [campaignpress.com/pricing](https://campaignpress.com/pricing)
2. Download premium plugin from your account
3. Install and activate plugin
4. Enter license key at **CampaignPress Pro > License**
5. Activate features you need
6. Optional: Schedule onboarding call
