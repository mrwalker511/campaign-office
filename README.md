## Description

CampaignPress is a comprehensive WordPress theme built specifically for political campaigns, candidates, and advocacy organizations. With purpose-built features and a focus on usability, CampaignPress helps you create a professional campaign website quickly and easily.

**Documentation:** [https://campaignpress.com/docs](https://campaignpress.com/docs)
**Support:** [https://campaignpress.com/support](https://campaignpress.com/support)

## Key Features

- **Campaign-Specific Custom Post Types**: Issues, Events, Endorsements, Team Members, and Volunteer Opportunities
- **Comprehensive Theme Options Panel**: Centralized control for all customization in one place
- **Demo Content Importer**: Get started quickly with pre-built sample content
- **Responsive Design**: Works beautifully on all devices
- **Accessibility Ready**: WCAG 2.0 AA compliant
- **Multiple Layout Options**: Sidebar right, sidebar left, or full-width
- **Color Scheme Presets**: Democrat Blue, Republican Red, Independent Purple, Green Party, and Neutral
- **Social Media Integration**: Built-in social sharing and profile links
- **Event Management**: Complete event system with dates, locations, and RSVP links
- **SEO Optimized**: Schema markup, Open Graph, and Twitter Cards
- **Translation Ready**: Full internationalization support

## Installation

### Automatic Installation

1. Log in to your WordPress dashboard
2. Navigate to **Appearance → Themes**
3. Click **Add New**
4. Search for "CampaignPress"
5. Click **Install** and then **Activate**

### Manual Installation

1. Download the theme ZIP file
2. Log in to your WordPress dashboard
3. Navigate to **Appearance → Themes**
4. Click **Add New → Upload Theme**
5. Choose the downloaded ZIP file and click **Install Now**
6. Click **Activate** to activate the theme

### After Activation

1. Go to **Appearance → Demo Content** to import sample content (optional)
2. Go to **CampaignPress** menu in admin to configure theme options
3. Navigate to **Appearance → Menus** to set up your navigation
4. Start customizing your campaign website!

## Frequently Asked Questions

### How do I import the demo content?

Go to **Appearance → Demo Content** in your WordPress admin panel. Click "Import Demo Content" to create sample issues, events, team members, endorsements, volunteer opportunities, pages, menus, and populate theme options.

### How do I change the color scheme?

Go to **CampaignPress → Design** tab in your admin panel. Choose from preset color schemes (Democrat Blue, Republican Red, Independent Purple, Green Party, Neutral) or create custom colors.

### How do I add campaign events?

Navigate to **Events → Add New** in your WordPress admin. Fill in the event details including date, time, location, and RSVP link. The event will automatically appear on your Events archive page.

### Can I use this theme for non-political purposes?

While CampaignPress is optimized for political campaigns, it can be adapted for advocacy organizations, non-profits, or any organization that needs custom post types for issues, events, and team members.

### Is the theme translation ready?

Yes! CampaignPress is fully translation ready with a `.pot` file included. You can translate it to any language using translation plugins like Loco Translate or Poedit.

### Does the theme work with page builders?

CampaignPress works with the WordPress block editor (Gutenberg) and is compatible with popular page builders like Elementor.

### How do I add my campaign logo?

Go to **Appearance → Customize → Site Identity → Site Logo** to upload your campaign logo. You can also control the logo width in **CampaignPress → Design → Logo Width**.

### Can I change the layout on individual pages?

Yes! Each page and post has a "Layout Options" meta box in the editor where you can choose Sidebar Right, Sidebar Left, No Sidebar, or use the default theme setting.
