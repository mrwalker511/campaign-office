**CampaignPress** is a sophisticated "Hybrid" WordPress theme designed for political campaigns.

*   **Target:** Local to national political campaigns.
*   **Model:** Freemium (Free essentials with a "Campaign Operating System" premium layer).
*   **Version:** 2.0.0 (Supports WP 6.4+).

### Technical Architecture
*   **Hybrid Structure:** Combines modern `theme.json` (FSE-style) settings with classic PHP templates (`header.php`, `footer.php`, `index.php`).
*   **Advanced Block System:** 8+ custom Gutenberg blocks built with React/Vite (Countdown, Donation, Volunteer etc.).
*   **Premium Layer:** Robust system for CRM, Field Ops, Compliance, and Analytics, strictly separated in `includes/premium/`.
*   **Design System:** Uses a sophisticated `theme.json` configuration for fluid typography and brand-specific colors (Democrat/Republican/Independent palettes).
