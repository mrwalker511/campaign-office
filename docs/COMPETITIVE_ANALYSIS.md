# CampaignPress Competitive Analysis

**Comparison with competing political campaign platforms**

---

## Executive Summary

CampaignPress occupies a unique position in the political campaign technology market. Unlike SaaS platforms that charge per-user or monthly fees, CampaignPress is a self-hosted WordPress theme with a freemium model. This provides campaigns with data ownership, hosting flexibility, and predictable costs.

---

## Market Landscape

### Category 1: Campaign Management SaaS Platforms
**Competitors:** NGP VAN, ActionNetwork, NationBuilder

### Category 2: WordPress Political Themes
**Competitors:** PoliticalWP, Candidate, Election Campaign

### Category 3: General Campaign Tools
**Competitors:** Mailchimp for campaigns, Google Workspace, social media schedulers

---

## Detailed Comparison

### 1. NGP VAN

**Overview:** Enterprise-grade SaaS platform used by Democratic campaigns

**Pricing:**
- Enterprise pricing (custom quotes)
- Typically $2,000-$10,000+ per election cycle
- Per-user fees

**Features:**
✓ Comprehensive voter database
✓ Advanced targeting
✓ Compliance tools
✓ Integration ecosystem
✗ Expensive for small campaigns
✗ Vendor lock-in
✗ No website building tools

**vs CampaignPress:**
- **CampaignPress advantage:** Free tier, self-hosted, includes website
- **NGP VAN advantage:** Larger voter database, established integrations
- **Best fit:** NGP VAN for major campaigns ($1M+ budgets), CampaignPress for local/state campaigns

---

### 2. NationBuilder

**Overview:** All-in-one SaaS platform for campaigns and advocacy

**Pricing:**
- Starter: $29/month (500 contacts)
- Bronze: $99/month (5,000 contacts)
- Silver: $249/month (50,000 contacts)
- Gold: $499/month (100,000 contacts)

**Features:**
✓ Website builder included
✓ CRM and database
✓ Email and SMS tools
✓ Donation processing
✗ Monthly recurring costs
✗ Contact limits
✗ Hosted platform only

**vs CampaignPress:**
- **CampaignPress advantage:** One-time annual fee, unlimited contacts (Professional tier), WordPress flexibility
- **NationBuilder advantage:** All-in-one platform, established ecosystem
- **Cost comparison:** NationBuilder Silver = $2,988/year vs CampaignPress Professional = $299/year

---

### 3. ActionNetwork

**Overview:** Progressive organizing and advocacy platform

**Pricing:**
- Free tier (limited)
- Plus: $25/month
- Pro: Custom pricing

**Features:**
✓ Progressive focus
✓ Email and SMS
✓ Event management
✓ Petition tools
✗ Limited website features
✗ Designed for advocacy, not campaigns
✗ Hosted only

**vs CampaignPress:**
- **CampaignPress advantage:** Full website builder, self-hosted, broader political spectrum
- **ActionNetwork advantage:** Petition tools, progressive network effects
- **Best fit:** ActionNetwork for advocacy groups, CampaignPress for candidate campaigns

---

### 4. Generic WordPress Political Themes

**Competitors:** PoliticalWP ($59), Candidate ($69), Election Campaign ($79)

**Typical Features:**
✓ WordPress theme
✓ Basic layouts
✓ Some custom post types
✗ No CRM
✗ No field operations tools
✗ Limited support
✗ One-time purchase, no updates

**vs CampaignPress:**
- **CampaignPress advantage:** Free tier, premium CRM/field ops, ongoing updates, professional support
- **Generic themes advantage:** Lower one-time cost
- **Verdict:** CampaignPress offers significantly more value for serious campaigns

- **Self-hosted** means data ownership and hosting choice

#### 2. Transparent, Predictable Pricing

- No contact limits in Professional tier
- Annual subscription (not monthly accumulation)

#### Primary Market: Local to State Campaigns ($50K-$500K budgets)
**Why CampaignPress wins:**

- Website + tools in one platform
- No technical expertise required
- Scales with campaign growth

**Competitors:**

#### Secondary Market: Small Federal Campaigns ($500K-$2M budgets)
**Why CampaignPress wins:**

- Dedicated support

**Competitors:**
- NationBuilder (more expensive)

#### Tertiary Market: Advocacy Organizations
**Why CampaignPress wins:**
- Multi-campaign support
- Data ownership

**Competitors:**
