# CampaignPress - Political WordPress Theme

**Version:** 2.0.0
**Requires:** WordPress 6.9+ | PHP 8.1+
**License:** GPLv3 or later

> A comprehensive WordPress theme that transforms your campaign website into a complete operations platform. Built for candidates, campaigns, and advocacy organizations.

## Overview

CampaignPress is a professional political WordPress theme designed to power winning campaigns. The **free version** provides everything you need to run a modern campaign website with advanced volunteer management, event coordination, fundraising tools, and accessibility compliance. The **premium version** transforms your site into a complete campaign operations hub with CRM, field operations, FEC compliance, and automation—**replacing expensive platforms like NationBuilder ($500-$1,000/mo) and NGP VAN ($1,500-$3,000/mo)**.

### Built for Real Campaigns

- **Launch faster** - One-click demo content and pre-configured templates
- **Raise more** - Integrated donation forms with 6 payment processors
- **Organize better** - Volunteer management and event RSVP systems
- **Stay compliant** - WCAG 2.1 AA accessibility and FEC compliance tools
- **Reach everyone** - Multi-language support for diverse communities

## Core Features

### Custom Gutenberg Blocks

Build compelling campaign pages with purpose-built blocks:

- **Hero Commander** - Dynamic hero sections with typewriter effects, parallax backgrounds, and call-to-action buttons
- **Donation Form** - Multi-tier fundraising forms with recurring donation support and payment processor integration
- **Progress Tracker** - Visual goal meters for fundraising, volunteer recruitment, and voter outreach
- **Countdown Timer** - Election day countdowns with customizable layouts
- **Policy Platform** - Showcase your positions on key issues
- **Event Organizer** - Display and manage campaign events with built-in RSVP
- **Volunteer Matcher** - Intelligent volunteer sign-up forms
- **Mission Control** - Campaign performance dashboard
- **Section Wrapper** - Layout control for complex page designs
- **Style Panel** - Advanced design controls within the editor

### Volunteer Management

Recruit, organize, and mobilize your field team with a complete volunteer management system:

- **Digital Database** - Capture comprehensive volunteer information including contact details, skills, interests, and availability preferences
- **Smart Organization** - Filter and search volunteers by status (new, contacted, active), skills, location, availability, and recruitment source
- **Bulk Actions** - Update multiple volunteers at once, export lists to CSV, and track recruitment sources
- **Volunteer Portal** - Self-service dashboard where volunteers can manage their profile, view assignments, and track hours
- **Shift Scheduling** - Create and manage volunteer shifts with capacity limits and signup tracking
- **Hours Tracking** - Log volunteer hours with verification workflow and activity categorization
- **Leaderboards** - gamified ranking system with top volunteer recognition by hours and activities
- **Flexible Placement** - Use shortcodes (`[cp_volunteer_form]`, `[cp_volunteer_portal]`, `[cp_volunteer_leaderboard]`) or blocks to add volunteer forms anywhere
- **Integration Ready** - Email hooks and action filters for automated communications and third-party integrations

### Event Management & RSVP

Coordinate rallies, town halls, and volunteer activities:

- **Built-in RSVP System** - Capture attendee information with capacity limits
- **Recurring Events** - Schedule daily, weekly, bi-weekly, or monthly events automatically
- **Smart Controls** - Set RSVP deadlines, track capacity, collect dietary preferences
- **Admin Dashboard** - View, filter, and export all event registrations
- **Flexible Display** - Use shortcodes or blocks to show events and RSVP forms

### Fundraising Tools

Accept donations and track progress toward your goals:

- **6 Payment Processors** - ActBlue, WinRed, PayPal, Stripe, Square, Donorbox
- **Quick Amount Buttons** - Pre-configured amounts ($25, $50, $100, $250, $500) plus custom
- **Recurring Donations** - One-time, monthly, quarterly, or annual giving
- **FEC Compliance Notices** - Automatic contribution limit warnings
- **Analytics Integration** - Track donation events in Google Analytics

### Multi-Language Support

Reach voters in their preferred language:

- **Translation Ready** - Full compatibility with WPML, Polylang, and TranslatePress
- **Language Switcher** - Dropdown or flag-based language selection
- **RTL Support** - Right-to-left layouts for Arabic, Hebrew, Persian, and Urdu
- **Complete Translation** - All custom post types, theme options, and content

### Design System

Professional, campaign-ready design:

- **Color Presets** - Democrat Blue, Republican Red, Independent Purple, Green Party, and Neutral options

## Installation

### Quick Start

1. **Upload Theme**
   - Download CampaignPress from your account
   - Go to **Appearance > Themes > Add New > Upload Theme**
   - Upload the `.zip` file and click **Install Now**
   - Click **Activate**

2. **Install Recommended Plugins**
   - Click **"Begin installing plugins"** in the admin notice
   - Recommended: Contact Form 7, The Events Calendar, GiveWP, Yoast SEO, Wordfence Security

3. **Import Demo Content** (Optional)
   - Go to **Appearance > CampaignPress Options**
   - Click **Import Demo Content** tab
   - Select your layout preference and click **Import**

4. **Customize Your Site**
   - Go to **Appearance > Customize**
   - Configure colors, typography, and layout options
   - Add your candidate information and campaign details

### System Requirements

- **WordPress:** 6.9 or higher
- **PHP:** 8.1 or higher
- **MySQL:** 5.7+ or MariaDB 10.3+
- **HTTPS:** Recommended for payment processing and security

## Development

### Local Development

```bash
# Clone into WordPress themes directory
cd wp-content/themes
git clone https://github.com/yourusername/campaignpress.git
cd campaignpress

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

### Tech Stack

- **Backend:** PHP 8.1+, WordPress 6.9+ APIs, MySQL/MariaDB
- **Frontend:** React (Gutenberg blocks), Modern CSS (no preprocessors), Vanilla JS
- **Build Tools:** Vite 5.0, Node.js 18+, Prettier, ESLint
- **Design System:** WordPress `theme.json` with design tokens

### Project Structure

```
campaignpress/
├── assets/                 # Client-side assets (CSS, JS, Fonts)
├── bin/                    # Executable tools and binaries (wp-cli)
├── blocks/                 # Custom Gutenberg blocks (React/PHP)
├── build/                  # Build configurations and scripts
├── docs/                   # Project documentation and guides
├── includes/               # Core theme logic and class includes
├── parts/                  # Template parts (block-based)
├── patterns/               # Block patterns
├── templates/              # Page templates
├── tests/                  # Test suites and test configuration
├── theme.json              # FSE design system configuration
├── functions.php           # Theme bootstrap
├── index.php               # Fallback template
├── style.css               # Theme metadata and global styles
└── package.json            # Tooling and dependencies
```
