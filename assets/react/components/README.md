# React Components

This directory contains shared React components used across the CampaignPress theme.

## Structure

- `/blocks/` - Gutenberg block components
- `/crm/` - CRM interface components (Premium feature)
- `/components/` - Shared/reusable components

## Development

Components are built using Vite and React. To build:

```bash
npm run build
```

To develop with hot reload:

```bash
npm run dev
```
